# 动态任务推演 Demo

用户给定的实现规格：Python 3.11+，Streamlit 三栏前端、FastAPI 逻辑层、DeepSeek 异步生成结构化任务，Plotly 分支树，ComfyUI 奖励概念图扩展。

界面采用浅色纸张与墨绿配色，面向技术策划使用。左侧调节等级、金币、血量、阵营及该阵营声望；中间生成并展示任务、前置条件、奖励和接受/拒绝/交好三个选项；右侧展示已生成节点和待探索的分支。任务尚未生成时显示明确的空态。

FastAPI 保存内存会话和节点状态快照。每个分支结算自身声明的金币、血量和声望变化；只有后续任务成功生成才提交节点。重试同一父节点与选项返回已有子节点，回溯探索其它选项从父节点快照开始，避免重复领奖。手动调节面板只用于下一次根任务生成。单次会话限制 12 层和 80 个节点，空闲两小时回收；重启清空会话。

任务 JSON 使用 Pydantic 严格校验，必须包含唯一的三种分支，前置条件必须满足当前状态，所有分支必须支付得起，接受选项的正向奖励与奖励面板一致。AI 输出无效时带校验反馈重新生成一次；真实模式请求失败时显示错误，不回退到离线数据。无 Key 也可主动使用标注清楚的离线模式。

DeepSeek 使用 httpx.AsyncClient、JSON Output 模式、包含玩家状态及有限历史的提示词。Key 仅在后端环境变量内读取。所有外部请求设超时；错误提示隐藏密钥和上游响应正文。前端使用 AsyncClient 请求 FastAPI，以 spinner 呈现等待过程。

ComfyUI 使用可替换的 API-format 工作流，注入奖励物品名称及英文概念图提示词，通过 /prompt、/history/{prompt_id}、/view 完成提交、异步轮询和图片展示。缺少服务或模型时给出配置提示，不展示伪造图片。提供 SD1.5 示例工作流及自定义工作流接入说明。

验证包括状态边界、无效任务拒绝、异步 DeepSeek 协议及纠错、分支幂等性和失败原子性、ComfyUI 完整协议模拟、Streamlit 交互测试与本地进程启动检查。真实 DeepSeek/ComfyUI 需用户提供 Key / 本地模型后测试。
