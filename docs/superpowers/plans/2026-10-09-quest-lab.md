# Quest Lab Implementation Plan

**Goal:** 交付可直接启动的中文动态任务推演 Demo。

**Architecture:** Streamlit 调用 FastAPI；FastAPI 校验模型、保存分支快照，并通过异步 httpx 访问 DeepSeek 和 ComfyUI。Plotly 展示真实节点及未探索选项。

**Tech Stack:** Python 3.11+ / FastAPI / Pydantic 2 / Streamlit / Plotly / httpx / pytest。

## Global Constraints

- 任务必须且仅包含接受、拒绝、交好三种分支。
- 真实 API 失败不自动改用离线模式；所有网络操作使用异步客户端和超时。
- Key 只从后端环境读取；用户输入使用受限字段；AI 文本不插入 HTML。
- ComfyUI 可选，启动 Demo 不依赖模型或系统 Graphviz。
