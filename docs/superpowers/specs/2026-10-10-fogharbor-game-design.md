# 雾港守灯人：免费像素素材小游戏设计

本设计已获用户批准并完成实现；用户补充约束：制作过程不经过C盘。

## 方向与实现选择

在现有 Python、Streamlit、FastAPI 项目上增加像素剧情冒险。它是四方向、回合制游戏，每次移动或战斗动作都由 Python 处理，游戏状态仍在 st.session_state。既有沙盘作为单独的策划模式保留。无需更换运行命令或安装桌面游戏引擎。

像素地图由Canvas呈现，鼠标和键盘动作回传Python状态机。

## 故事与角色

游戏名：《雾港守灯人》。预计首轮体验5–10分钟。

雾港灯塔熄灭，归航船只困在迷雾。玩家扮演见习守灯人莉亚，受命找回散落在旧遗迹里的三枚灯芯碎片。

- 莉亚：可操控角色，显示像素形象、生命、魔力、金币和背包。
- 洛恩：老守灯人，交代委托、解释灯塔机关、给出最终修复对话。
- 艾芙：药师，提供支线与药剂商店。
- 熄灯者：最终首领，阻拦灯芯修复；有蓄力提示，玩家可选择防御降低伤害。

## 两张关卡地图

两张手工布局的10×10地图，保持清晰的探索路径，不再用随机符号格充当剧情关卡。

1. 避风站：安全区，包含出生点、两名NPC、补给与通往遗迹的入口。
2. 灯塔遗迹：房间、墙、走廊、陷阱、宝箱、普通敌人、草药、灯芯碎片以及首领房。

墙不可穿越。门与入口只在满足条件时开放。出入地图保留已打开宝箱、已击败敌人和已收集物品，避免刷取。任务物品有保证可达的路径。点击相邻格或使用方向按钮移动，邻近NPC后提供互动按钮；对话和互动不推进战斗。

## 游戏循环与任务内容

1. 标题画面开始新游戏，简短开场交代目标。
2. 与洛恩交谈接取主线，获得起步药剂。
3. 探索遗迹：开宝箱、寻找3枚灯芯碎片、与普通敌人战斗。
4. 集齐碎片后打开首领房，挑战熄灯者。
5. 返回洛恩处修复灯塔，展示完成画面和船队归航的结局。

支线：艾芙请玩家带回遗迹草药；交付后给予治疗奖励与额外对话。支线非通关前置，不会卡主线。

失败：生命耗尽后显示失败原因，可重新开始。重新开始清空本局世界与背包，已有策划模式数据按原入口管理。

## 战斗、物品与反馈

- 保留现有高伤长CD、低伤短CD回蓝技能，增加药剂和防御行动。
- 普通敌人使用不同名字、形象和HP/ATK组合，让“低血量斩杀”与“技能真空”有不同决策价值。
- 首领用固定回合节奏展示蓄力预告，防御消耗一回合并减伤；伤害记录取实际HP变化。
- 药剂在战斗和探索中均可使用，背包计数不得为负，HP不超过上限。首次赠送与商店购买均只能按规则结算。
- 打开箱子、捡起碎片、受击、恢复与击杀均提供明确文本反馈；任务面板展示当前阶段、碎片数和下一目标。
- 角色、NPC与敌人使用真实像素素材，不使用字母和几何符号作为最终形象。
